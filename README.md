# Dopamine

Статический магазин на ES-модулях, CSS, GSAP и ScrollTrigger. Исходная папка проекта была пустой. Реальный ассортимент и сервис оформления не предоставлены: опубликованный каталог намеренно пуст, заказы не имитируются.

## Запуск

```sh
npm install
npm test
npm run build
npm run dev
```

Предпросмотр: http://127.0.0.1:4173. Сборка: `dist/`. Node 20+. Зависимость: только GSAP. Шрифты хранятся локально, внешних запросов Google Fonts при посещении сайта нет.

## Реальные данные

Единственный источник ассортимента — `src/data/catalog.json`:

```json
{
  "version": 1,
  "categories": [{"id": "CATEGORY_ID", "title": "Реальная категория"}],
  "products": [{
    "id": "REAL_SKU",
    "slug": "real-product-slug",
    "title": "Реальное название",
    "categoryId": "CATEGORY_ID",
    "description": "Описание из каталога",
    "featured": true,
    "images": [{"src": "/assets/products/actual-photo.webp", "alt": "Описание реального фото", "width": 1200, "height": 1400}],
    "variants": [{"id": "REAL_VARIANT_ID", "label": "Реальный вариант", "price": 100000, "stock": 3}]
  }],
  "rooms": []
}
```

Цена — целое число копеек, валюта RUB; пример выше поясняет схему и не входит в каталог. Stock — целое доступное количество. Второе изображение включает смену ракурса на hover; featured включает горизонтальную галерею. Категории выводятся исключительно из реальных данных. Сборка отклоняет некорректные SKU, варианты, изображения, цены и маркеры.

Интерьерные сцены: `rooms: [{id, title, image: {src,alt,width,height}, markers: [{productId,x,y}]}]`; координаты — проценты 0–100. Комната выводится только при наличии фото и действительных SKU. Товарные карточки доступны по `#product/slug`; нативный dialog поддерживает Escape и фокус. Увеличенное фото открывается отдельным dialog.

## Подключение оформления

В `src/data/settings.json` заполнить подтвержденные контакты, условия доставки/возврата и `checkoutEndpoint`. Без endpoint покупка отключена. Клиент отправляет POST JSON `{currency:"RUB",lines:[{productId,variantId,quantity}]}`. Сервер обязан заново определить цены и остатки, создать checkout session и вернуть `{checkoutUrl:"https://..."}`. Клиентские цены и localStorage не являются доверенным источником для оплаты. Платежные и персональные данные клиент не собирает. Реализация серверного commerce API, оплата, доставка и обработка заказов отсутствуют и требуют подключения реального магазина.

## Motion и доступность

- Нативная прокрутка, GSAP intro и единая scrub timeline для истории.
- CSS sticky для истории; на мобильных сохраняется обычная вертикальная прокрутка.
- GSAP matchMedia, очистка timeline/listeners, fine pointer only для курсора/магнитов.
- При reduced motion нет preload/параллакса/бегущей строки, состояния истории читаются последовательно.
- Без GSAP остаются контент, навигация, каталог и корзина.
- Корзина localStorage сверяется с текущими SKU и остатками, синхронизируется между вкладками.
- Skeleton показан только на время реального получения каталога.

Логотип выводится из оригинального изображения через встроенный SVG фильтр белых пикселей и кадрирование. Шапка, preload и footer используют один кешируемый оригинал. Это не перерисовка шрифтом. Исходник сохранен без изменений в `src/assets/brand-original.png`.

## Проверки и ограничения

`npm test` проверяет бизнес-инварианты корзины и каталога на изолированных синтетических данных. Эти данные не входят в сборку. Browser QA и результаты сборки описаны в `QA.md`. Производственные LCP/CLS/INP и конверсия не подтверждены: для них необходимы реальные товары, API и замеры на целевых устройствах. Нет выдуманных отзывов, скидок, продаж, контактных данных или товарных изображений.

Референсы: [SLOI](https://sloi.ai/) — композиционный ритм и контраст масштаба; [GSAP documentation](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) — API прокрутки. Pinterest search недоступен для автоматического просмотра.
