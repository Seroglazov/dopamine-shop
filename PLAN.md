# Dopamine — аудит и план реализации

## Аудит, 20.10.2026

Исходная рабочая папка содержит только пустой Git-репозиторий. Стек, страницы, каталог, категории, фотографии, корзина, оформление заказов и серверная интеграция отсутствуют. Сохранять или мигрировать существующую бизнес-логику пока нечего. Пользователю отправлен запрос о расположении проекта и данных.

Предоставлен оригинал фирменного изображения. Логотип используется непосредственно из оригинала через SVG-маску, без набора похожим шрифтом. SLOI изучен как референс композиции и поведения: масштабная медийная сцена, компактная навигация, контраст масштабов, последовательное раскрытие контента. Pinterest недоступен для автоматического чтения.

## Решение

Легкий магазин на нативных ES-модулях с GSAP + ScrollTrigger; обычная прокрутка браузера и CSS smooth scrolling. Не нужны React, WebGL, Lenis и дополнительные библиотеки анимации. Статическая сборка пригодна для подключения commerce API. Каталог пуст до получения реальных данных; вымышленные товары, цены, отзывы и скидки не публикуются. Оплата и отправка заказов требуют подтвержденного серверного API.

## План по файлам и компонентам

1. `src/styles/tokens.css` — цвета, локальные шрифты, типографика, spacing, easing, durations, focus и reduced motion.
2. `src/index.html`, `src/styles/main.css` — Header, Hero, брендовая бегущая строка, Story, Palette Playground, Catalog, Footer, доступные dialog-панели меню и корзины.
3. `src/assets/brand-original.png`, `src/assets/logo.svg` — оригинальный брендовый материал и маска для точного логотипа.
4. `src/js/motion.js` — GSAP intro, scroll timeline, reveal, магнитные кнопки, курсор, прогресс, управление жизненным циклом.
5. `src/js/commerce.js` — проверка реальных данных, фильтрация/сортировка, варианты, корзина с localStorage, контроль остатков и итогов.
6. `src/js/catalog.js` — реальные карточки, фильтры, PDP dialog, галерея и zoom, related products, featured horizontal gallery. Пустые состояния при отсутствии ассортимента.
7. `src/js/room.js` — схема интерьерных сцен и товарных маркеров; рендер только при наличии настоящего фото и соответствующих SKU.
8. `src/js/app.js` — маршруты через URL hash, диалоги, поиск, цветовой playground, accordion, корзина и безопасный переход к checkout API.
9. `src/data/catalog.json`, `src/data/settings.json` — единственная точка подключения достоверного ассортимента, категорий, фото, контактов и серверного checkout. По умолчанию пустые значения.
10. `scripts/build.mjs`, `scripts/serve.mjs` — воспроизводимая статическая сборка и локальный preview.
11. `tests/commerce.test.mjs` — значимые проверки валидации, остатков, количества, вариантов, фильтрации и восстановления корзины; тестовые SKU не попадают в сайт.
12. `README.md` — запуск, схема данных, подключение магазина и честные ограничения готовности.

## Проверка этапов

- Node tests и синтаксические проверки модулей; успешная сборка.
- Browser QA desktop и mobile: меню, фокус/Escape, каталог/поиск, корзина, accordion, palette и отсутствие overflow.
- Reduced motion и работа без GSAP: контент доступен, нет зависшего loader.
- Production Core Web Vitals нельзя подтвердить без реального каталога, серверного API и полевых измерений.
