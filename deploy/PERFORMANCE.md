# Загрузка и анимации

`npm run build` создаёт адаптивные WebP-копии фотографий (480/960/1600 px)
и готовые Brotli/Gzip-версии текстовых ресурсов. Исходники фотографий сохраняются.
Для карточек используется `ResponsiveImage`; увеличение фотографии в карточке товара
по-прежнему загружает оригинал. Не добавляйте `public/assets/optimized/` в Git:
производные файлы создаются при сборке, а карта размеров хранится в `src/lib/image-variants.json`.

Проверки HTTP используют результат сборки, поэтому порядок проверки:

```
npm run build
npm test
npm run typecheck
```

При публикации необходимо обновлять и `dist/`, и `server/http.mjs`:
сервер выбирает Brotli/Gzip по Accept-Encoding, использует ETag и кеширует
файлы с хешем в имени на год. HTML и каталог всегда перепроверяются;
обычные ресурсы кешируются на сутки. Секреты и серверные файлы не публикуются.

Анимации не перекрывают содержимое заставкой. Обработчик прокрутки обновляется
не чаще кадра, пересчёты ScrollTrigger объединяются. 3D загружается после первого
показа страницы; вне экрана и в скрытой вкладке непрерывный рендеринг останавливается.
На сенсорных устройствах ограничены разрешение холста и частота кадров.
Колесо мыши сглаживается Lenis на устройствах с точным указателем;
сенсорная прокрутка и прокрутка диалогов остаются нативными.
При включении «Уменьшения движения» сглаживание и декоративные анимации отключаются.
