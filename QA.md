## Реализовано, требует дальнейшей проверки на данных магазина

- Horizontal featured gallery включается реальными featured товарами; mobile — нативный swipe.
- Сопутствующие товары и маркеры комнаты включаются по реальным категориям/SKU и предоставленным фото.
- Shared element transition работает в поддерживающих View Transition API браузерах; остальные используют обычное открытие dialog.
- Reduced motion предусмотрен CSS и GSAP matchMedia; системный режим на устройстве пользователя в ходе browser QA не переключался.
- Платежный API отсутствует. Отправка заказа, оплата и доставка не проверены и недоступны до подключения.
- Core Web Vitals не измерены как production показатели. Нет утверждения о достижении LCP ≤2.5s, CLS ≤0.1 или INP ≤200ms. Сохраненный оригинал PNG — около 1.48MB; перед коммерческим запуском нужны оптимизированные экспортированные брендовые файлы и реальные responsive фото товаров.
